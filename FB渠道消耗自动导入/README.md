# FB 广告消耗自动导入 SmartBI

每天 8:00 自动从 Facebook Marketing API 拉取广告消耗数据，转换格式后导入 SmartBI，完成后发送钉钉通知。

## 流程

```
任务一：下载消耗.py → 转换脚本.py ─┐
                                    ├→ 上传BI_合并.py → 钉钉通知
任务二：下载KOL消耗.py → 转换KOL格式.py ─┘
```

- 任务一：课包城市消耗数据回写（按城市+课包聚合）
- 任务二：投放账户数据回写（广告级别明细，含视频播放、潜客等扩展字段）

## 文件说明

| 文件 | 用途 |
|------|------|
| `run_all_v2.py` | 主编排脚本，串联下载→转换→上传→通知 |
| `下载消耗.py` | 任务一：从 FB API 下载基础消耗数据 |
| `下载KOL消耗.py` | 任务二：从 FB API 下载扩展字段数据 |
| `转换脚本.py` | 任务一：转换为课包城市维度格式 |
| `转换KOL格式.py` | 任务二：转换为投放账户维度格式 |
| `上传BI_合并.py` | Selenium 自动上传两个文件到 SmartBI |
| `发送钉钉.py` | 钉钉 Webhook 通知 |
| `启动主浏览器.bat` | 启动 Chrome（带远程调试端口 9222） |
| `设置开机自启.bat/.ps1` | 注册 Chrome 开机自启 |
| `每日自动运行.bat` | Windows 计划任务入口 |
| `注册每日任务.bat` | 注册每天 8:00 的 Windows 计划任务 |
| `取消每日任务.bat` | 取消计划任务 |
| `手动测试全流程.bat` | 手动触发一次完整流程 |

## 部署步骤

### 1. 环境准备

- Windows 10/11
- Python 3.8+（需在 PATH 中）
- Chrome 浏览器
- Python 依赖：`pip install openpyxl selenium`

### 2. 配置

复制 `.env.example` 为 `.env`，填入实际值：

```
FB_ACCESS_TOKEN=你的Facebook长期token
BI_USERNAME=BI登录账号
BI_PASSWORD=BI登录密码
DINGTALK_WEBHOOK=钉钉机器人webhook地址
```

### 3. 准备规则表

将 `FB账户消耗底表.xlsx` 放在同目录下（包含"地区名称对照表"和"账户-平台映射"工作表）。

### 4. 启动浏览器

双击 `启动主浏览器.bat`，登录 SmartBI，打开两个上传页 tab：
1. 海外投放课包城市维度数据填报 → 课包城市消耗数据回写
2. 海外投放数据产品维度数据填报 → 投放账户产数据回写填报模板

建议右键 tab → "固定标签页"。

### 5. 测试

双击 `手动测试全流程.bat`，确认两个任务都成功。

### 6. 注册定时任务

右键 `注册每日任务.bat` → 以管理员身份运行。

### 7. 设置开机自启

双击 `设置开机自启.bat`，确保重启后 Chrome 自动启动。

## 注意事项

- FB Access Token 有效期约 60 天，过期后需更新 `.env`
- 浏览器需保持两个上传页 tab 打开（固定标签页不会丢失）
- 电脑需在 8:00 前开机（或开机后自动补跑）
- 钉钉通知会报告成功/失败及关键指标
